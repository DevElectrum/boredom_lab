# Boredom Lab 🧪

A collection of tiny, strange, and occasionally delightful experiments.

We dream up ideas, build playable prototypes, and keep the fun ones. No deadlines, grades, or pressure to finish anything.

## What belongs here?

- Interactive toys and experiments
- Silly simulations and creative tools
- Mini-games and curious web projects
- Anything else that sounds fun for an afternoon

Each project gets its own folder. Browser-based creations are preferred when practical, so they can run on a phone or computer.

**Rule zero:** Fun first. It's okay to abandon an experiment and try something new.
